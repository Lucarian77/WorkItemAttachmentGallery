# Privacy Policy

Work Item Attachment Gallery does not collect, store, sell, or transmit user data to external services.

The extension runs inside Azure DevOps and uses Azure DevOps extension APIs to read and manage work item attachments.

Attachment data is used only within the user's Azure DevOps session to display previews, open files, download files, upload files, rename attachments, update comments, and remove attachment relations from work items.

No telemetry, analytics, or third-party tracking is included.
